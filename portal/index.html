1. Installation Guide

  1. Download MediHisaab-Setup-1.0.0.exe from the button above.
  2. Double-click the installer and follow the standard setup wizard.
  3. Choose an installation directory (defaults to your user programs folder).
  4. Launch the application using the created MediHisaab Desktop shortcut.
  5. Complete the 1-time First-Run Setup (Store Name, Drug License No., Admin Username & Password).

2. Multi-Counter LAN Setup

Run on multiple counter terminals simultaneously without separate databases:

  1. On the Main PC, launch using shortcut: MediHisaab (LAN Server Mode).
  2. Allow incoming traffic through Windows Firewall once:
netsh advfirewall firewall add rule name="MediHisaab LAN" dir=in action=allow protocol=TCP localport=38291 profile=private

3. On Counter 2, Counter 3, etc., open any browser and type: http://[SERVER-IP]:38291

3. Backup & Restore Guide

Safeguard sales history, inventory batches, and customer ledgers:

  • Location: %LOCALAPPDATA%\PharmacyApp\backups\
  • Manual Backup: Open Settings / Reports > Disaster Recovery > Click Create Hot Backup.
  • USB Backup: Copy the generated .pbk backup file to an external USB drive weekly.
  • Safety: Upgrades and uninstallations never delete existing business data.

4. Hardware & Peripherals

  • Barcode Scanners: Plug-and-play USB HID keyboard emulation supported natively on all barcode inputs.
  • Thermal Receipt Printers: Compatible with 80mm and 58mm ESC/POS thermal printers via USB and Windows print spooler.
  • Cash Drawers: Standard RJ-11/RJ-12 cash drawers triggered via printer kick pulse (ESC p 0 25 250).
  • A4 / Laser Invoices: Full GST tax invoices printable directly to any standard laser or inkjet printer.

5. Client Licensing & Evaluation

Each pharmacy receives an offline-signed Ed25519 asymmetric license token:

  • Format: LIC-CLXXXX-YYYYMMDD-XXXX.json
  • Instant Free Trial: Sign up directly from the desktop app first launch for automatic free evaluation trial activation.
  • Terminal Count: Configurable counter terminals (1–20) with LAN support.
  • Importing: In-app Settings > License > Upload license file, or auto-activate on first launch.
  • Offline Sovereignty: Licenses are verified 100% offline via embedded Ed25519 public key. Zero remote lockout of local data.

6. Data Privacy & Offline Architecture

MediHisaab is engineered for complete data sovereignty and local compliance:

  • 100% Local Database: All sales invoices, medicines, customer ledgers, and doctor details are stored strictly in your local SQLite database at %LOCALAPPDATA%\PharmacyApp\data\pharmacy.db.
  • Zero Telemetry of Patient Data: Patient names, prescriptions, transactions, and sales figures are NEVER transmitted to the vendor, licensing server, or third parties.
  • Full Offline POS Operations: Routine counter billing, barcode scanning, stock lookups, and receipt printing do not require internet access after activation.
